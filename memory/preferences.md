# Preferences

User preferences for coding style, tools, workflows, and communication. Update when preferences are expressed.

## Format

- **Category**: Preference detail

## Workflow

- **Always use plan mode first** — before implementing anything, plan it out. No exceptions.
- **Ra boots by default** — every session starts as Ra. No need to invoke `/ra` manually.
- **Continuous learning** — Ra observes working patterns, choices, and implicit preferences every session. Not just when asked.
